Binary Notation

Computers store everything as tiny on/off choices. Binary is how we write those choices using only 0 and 1.

Powers of 2

Each binary place has a value. Moving left doubles the value.

Place 27 26 25 24 23 22 21 20
Value 128 64 32 16 8 4 2 1
Bit 1 0 1 0 1 0 1 1

10101011 means add the columns where the bit is 1: 128 + 32 + 8 + 2 + 1 = 171.

Challenge: The values are 1, 2, 4, 8, 16... What is the rule for the next value?

General idea: place n has value 2^n. A binary number is the sum of bit x 2^n.

8-bit and 16-bit

  • 1 bit stores 2 choices: 0 or 1.
  • 8 bits make 1 byte and can represent 2^8 = 256 patterns.
  • 16 bits can represent 2^16 = 65,536 patterns.
  • Patterns can stand for numbers, letters, symbols, colors, sound samples, or instructions.

Challenge: If 8 bits make 256 patterns, how many patterns do 4 bits make?

Text: ASCII and Unicode

  • ASCII maps numbers to common English letters, digits, and symbols.
  • Example: decimal 65 represents uppercase A in ASCII.
  • Unicode supports many languages, symbols, and emoji.
  • UTF-8 is a common Unicode format that uses 1 to 4 bytes per character.

Idea: characters are not magic. They are numbers with agreed meanings.

Build the Rule

  • Start with one bit: 0 or 1. How many choices?
  • Add a second bit: 00, 01, 10, 11. How many choices?
  • Did the number of choices add 2, or multiply by 2?
  • Complete the pattern: 2, 4, 8, 16, __, __.
  • Write the shortcut rule using an exponent.
Key idea: position n has value 2^n.
For k bits, total patterns = 2^k.
Largest unsigned value with k bits = 2^k - 1.
